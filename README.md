# Swaroop Portfolio

Premium one-page Next.js 15 portfolio built from the supplied wireframe.

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Included

- Dark/light mode with persisted preference
- Responsive floating navigation and active-section state
- Framer Motion entrance and scroll animations, reduced-motion support
- Pausable skill marquees, project dashboards, and curved journey routes
- Local portrait and downloadable résumé in `public/`
